# What is dashAI?

dashAI is an innovative open source platform that empowers users to explore a wide range of Machine Learning (ML) algorithms through an interactive graphical interface, with no programming required.

The platform unifies interaction with ML models across different application domains, including tabular data analysis and natural language processing. dashAI aims to democratize ML adoption, making it more accessible for organizations and educational institutions.

## Key Capabilities

- **No code ML experimentation**: train, evaluate, and compare models without writing a single line of code
- **Multitask support**: tabular classification, regression, text classification, translation, and generative AI
- **Extensible via plugins**: add new models, tasks, and converters without touching the core platform
- **Reproducible experiments**: every configuration, split, and metric is recorded for full traceability
- **Transparent library integration**: uses Scikit-learn, Hugging Face, PyTorch, TensorFlow, and Keras under the hood, invisible to the user

## Open Source

dashAI is hosted on [GitHub](https://github.com/DashAISoftware/DashAI) under the MIT license. Contributions from the community are welcome, whether adding new ML components, improving the interface, or extending documentation.

# Aplicar Convertidores

Este tutorial te guiará a través del proceso de convertir datos en un dataset.
Con el convertidor, puedes:

- Normalizar datos
- Codificar datos categóricos
- Convertir tipos de datos
- ¡Y mucho más!

## Requisitos Previos

Antes de comenzar, asegúrate de tener:

- Un dataset en dashAI

Por defecto, el convertidor procesa todas las columnas y filas del dataset.
Sin embargo, puedes seleccionar columnas específicas para transformar y el número de filas de las que aprender.

Para refinar el alcance del convertidor:

- Haz clic en el ícono de tres columnas junto al convertidor para establecer su alcance.
- Selecciona las columnas específicas que deseas transformar.
- Define el número de filas de las que el convertidor debe aprender.
- Haz clic en "Guardar" para aplicar esta configuración.

## Consejos y Buenas Prácticas

- Puedes usar el módulo de Exploración para navegar por el dataset y ver los datos que necesitas convertir.
- Comienza con una conversión simple y agrega gradualmente más convertidores y transformaciones complejas.
- Asegúrate de que tu convertidor esté correctamente configurado para obtener el resultado deseado.
- El convertidor intentará modificar los datos en su lugar, añadiendo nuevas columnas solo al final del dataset cuando sea necesario.
- Asegúrate de que el convertidor sea compatible con el tipo de datos que seleccionaste para la conversión.
- Verifica los resultados de la conversión para asegurarte de que se obtenga el resultado deseado.

## Solución de Problemas

- Problemas comunes:
  - Falta el índice de la columna objetivo para convertidores supervisados
  - Tipos de datos incompatibles
  - El convertidor no converge debido a sus parámetros

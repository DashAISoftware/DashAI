# Explorar un Dataset

Este tutorial te guiará a través del proceso de explorar datos en un dataset usando dashAI.

Con las Exploraciones, puedes visualizar y analizar tu dataset para obtener información sobre su estructura y contenido.
Esto es especialmente útil para comprender los datos antes y después de aplicar transformaciones o entrenar modelos.

## Requisitos Previos

Antes de comenzar, asegúrate de tener:

- Un dataset cargado en dashAI

:::

## Consejos y Buenas Prácticas

- Lee la documentación de cada explorador para comprender su propósito.
- Usa el ícono de ayuda para obtener más información sobre cada explorador y sus parámetros.
- Prueba distintos exploradores para obtener información sobre tu dataset.
- El proceso de edición sigue los mismos pasos que el proceso de creación, por lo que puedes editar los exploradores de manera similar a como los creaste.

## Solución de Problemas

- Si la ejecución de un explorador falla, verifica los parámetros y las columnas seleccionadas.
- Si no puedes guardar una configuración de columnas, asegúrate de que tu selección cumpla con los requisitos del explorador.
- Después de realizar cambios en los datasets, debes volver a ejecutar los exploradores para ver los resultados actualizados. Esto sobreescribirá los resultados anteriores.
- Si encuentras errores, revisa los registros para obtener más información.

# Cargar un Dataset

Este tutorial te guiará a través del proceso de cargar un dataset en dashAI.

## Formatos Compatibles

dashAI admite varios formatos de datasets:

- Archivos CSV (.csv)
- Archivos Excel (.xlsx, .xls)
- Archivos JSON (.json)
- Datasets de imágenes (como archivos .zip)

  - Encabezado (el número de fila donde se encuentran los nombres de columna)

## Consejos y Solución de Problemas

- Asegúrate de que tu archivo esté en un formato compatible
- Verifica los límites de tamaño de archivo (3 GB para el dataset)
- Verifica la integridad de los datos antes de cargarlos
- Asegúrate de seleccionar el cargador de datos correcto para el formato de tu dataset
- Revisa el resumen del dataset para detectar errores

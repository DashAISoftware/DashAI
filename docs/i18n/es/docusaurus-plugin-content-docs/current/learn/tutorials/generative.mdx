# Generar Contenido con IA Generativa

Este tutorial te mostrará cómo usar las capacidades de IA generativa de dashAI.

Con la sección generativa, puedes:

- Generar texto con modelos LLM como Qwen, Llama y más
- Generar imágenes con Stable Diffusion y otros modelos de imágenes
- Generar imágenes guiadas por imágenes y texto.

## Requisitos Previos

Antes de comenzar, se recomienda tener:

- GPU NVIDIA con soporte CUDA (no es obligatorio, pero sí recomendado para mejor rendimiento)

## Consejos y Buenas Prácticas

- Algunas tareas y/o modelos generativos pueden tardar más tiempo en completarse, así que ten paciencia.
- Asegúrate de configurar los parámetros del modelo según tus necesidades, ya que pueden afectar significativamente la salida.
- Usa la función de historial para rastrear los cambios y revertir a configuraciones anteriores si es necesario.
- Experimenta con distintos modelos y parámetros para encontrar la mejor opción para tu caso de uso.

## Solución de Problemas

- Problemas comunes:
  - Si la generación falla, verifica la configuración del modelo y asegúrate de que todos los parámetros requeridos estén establecidos correctamente. (por ejemplo, el ancho y la altura para la generación de imágenes deben ser divisibles por 8)
  - Si tu computador se queda sin memoria, la generación puede fallar.
  - El modal de error que aparece cuando ocurre un error no muestra un mensaje preciso del error; en su lugar, revisa los registros de la consola del navegador para obtener más información.
